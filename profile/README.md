## Hi there 👋

Welcome to ***anvil-language***, The home of the anvil interpreter, language server and vs code extension. 

Anvil started as a compiler written in C for windows. Though I had to leave that idea behind because C became tedious to debug and work through. But that is when it hit me, Why don't I use go to make a language, so what is what this is. Several months of research and a single days worth of programming. It is truly amazing what this little tool can do and now I am sharing it with all of you. I hope you enjoy it.

## Contribution Guidelines

Well as outlined in the contribution rules in the main repo You can contribute with anything you want as long as it is code, is useful and has not already been added. Sure you can fix errors and bugs but just don't add features that we already have. And please do not break the code of conduct.
